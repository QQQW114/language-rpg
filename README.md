# 言灵 · Language RPG

一个由大语言模型驱动的中文文字 RPG / 互动小说前端。

玩家选择故事大纲、角色出身、世界书与随机事件后，由多个模型协作推进旅程：

- **故事模型**：根据设定、历史、长期记忆、背包、人物关系、场景、阶段焦点与玩家行动生成正文。
- **决策模型**：根据最新故事提取选项、道具变化、人物关系、场景、时间与天气。
- **阶段判断模型**（执笔模式 · 每回合最先跑）：分析玩家最新输入、节奏（沉浸 / 探索 / 推进 / 快进）与当前阶段进度，告诉故事模型本回合该聚焦哪一件微节拍，避免一回合压缩多步。
- **设定守护者**（执笔模式 · 每回合）：故事生成前扫描世界书与玩家输入，给出"必须遵守"的设定补丁、世界书候选、环境侧反应建议、偏离风险预警。
- **主弧模型**（执笔模式 · 创建旅程时）：基于大纲、出身、世界书生成不绑定回合的阶段化主弧，作为故事推进的母锚。
- **叙事导演 / 逻辑审校 / 长线随机事件**（执笔模式 · 隔轮跑）：维护节奏、连续性与剧情驱动事件。
- **记忆模型**：周期性整理外观、服装、承诺、线索、关系等长期一致性信息（含世界书一致性 + 大纲对齐）。
- **摘要模型**：在历史过长时压缩早期上下文（保留伏笔与关键回收弹药）。

项目是纯前端应用，所有设置、存档与自定义内容默认保存在浏览器 `localStorage` 中。

## 主要功能

- 导入或调用模型生成故事大纲、角色出身、世界书、随机事件与开局场景。
- **游历模式**：模型根据世界观生成故事正文和行动选项，玩家通过选择分支推进旅程；可配置每隔若干回合获得一次自由输入机会，支持有限回合与无尽模式。
- **执笔模式**：面向更强自定义与共同写作，默认每回合自由输入；通过阶段化主弧 + 玩家节奏感知 + 设定守护 + 叙事导演 + 逻辑审校等多模型协作维持小说化方向与一致性。
- 支持背包道具、NPC 好感与细节、场景跳转、时间天气、记忆锚点、聊天记录编辑和重新生成。
- 支持导出聊天记录 Markdown，以及可分享 / 导入的完整旅程包 JSON。

## 特色功能

- **阶段化叙事**：故事按"阶段 + 节拍"推进，不绑死回合数。玩家自己控制节奏，模型识别"沉浸 / 探索 / 推进 / 快进"四档自动调整粒度，慢玩家不被追着走。
- **设定守护者**：每回合扫描世界书与玩家输入，捕捉"瞎发挥"风险、给出环境侧主动反应建议、自动累积玩家偏好画像。
- **执笔辅助链路**：
  - 主弧生成（基于大纲 + 世界书）。
  - 叙事弧 / 剧情驱动长线随机事件。
  - 故事生成前置设定守护与玩家意图分析。
  - 环境侧主动反应建议（导员 / 室友 / NPC 等可能主动联系主角）。
  - 玩家偏好画像 + 节奏感知。
  - 逻辑审校与连续性修复建议（按 severity 分级注入）。
  - 随故事推进的世界书候选补充系统（玩家可一键沉淀）。
- 加载状态古风文案：每个模型跑时显示对应文案（"心镜映念 · 揣度此意"、"世书守护 · 查阅设定"等）。
- 高度可自定义的故事流程：严格自定义提示词、详细大纲、执笔模式独立提示词链路。
- 模型辅助生成世界书、出身、剧情大纲、随机事件与开局。
- 随故事更新的场景、世界状态、时间、天气与长期记忆。
- 背包道具系统与随故事变化的人物关系。

## 快速开始

### Windows

双击：

```bat
start.cmd
```

首次启动会自动执行 `npm install`。

### macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

启动后访问：

```text
http://127.0.0.1:5173
```

## 首次使用

1. 进入「设置」。
2. 填写：
   - API Base URL
   - API Key
   - 请求格式
   - 故事模型
   - 决策模型
3. 按需填写：
   - 摘要模型
   - 长期记忆模型
   - 随机生成模型（执笔辅助模型默认复用此设置）
4. 返回主页，点击「启程 · 开始新旅程」。


## 推荐模型配置

推荐：`deepseek-v4-pro` / `deepseek-v4-flash` 或能力相近的长上下文模型。

项目已参考 DeepSeek V4-pro 角色扮演提示词格式做了一定优化：故事模型可在设置页切换「默认」「DeepSeek V4 · 主角特化」「DeepSeek V4 · 指令遵循特化」三种模式。

- **故事模型**：`deepseek-v4-pro` —— 故事生成模型，越强越好。
- **决策模型**：`deepseek-v4-flash` —— 场景轮换、人物关系、背包道具。
- **摘要 / 记忆模型**：`deepseek-v4-flash` —— 压缩上下文 + 整理稳定事实。
- **随机生成模型**：`deepseek-v4-pro` —— 生成世界书、人设、随机事件、主弧；越强越好（这是被多个执笔辅助模型复用的设置）。

## 存档与数据

本项目主要使用 Zustand persist 写入浏览器本地存储：

- `lrpg.settings`：模型 API、温度、记忆设置、故事风格等。
- `lrpg.games`：存档、聊天记录、背包、NPC、场景、长期记忆、主弧、阶段判断状态等。
- `lrpg.content`：自定义故事大纲、出身、世界书、随机事件。

如果更换浏览器、清理站点数据或换设备，本地数据可能丢失。建议使用「旅程包」导出重要存档。

> API Key 与对话记录 只保存在本地浏览器 `localStorage`，不会被项目主动上传到其他地方。

> 注：阶段化叙事架构改动后，**之前版本的执笔旅程包不再兼容**——旧存档没有主弧数据会被识别为"旧版 · 不可继续"。请重新创建旅程。

## 内容导入 / 导出

- 「书库」中可以管理故事大纲、出身、世界书、随机事件。
- 「游戏页」可以导出：
  - 聊天记录 Markdown
  - 完整旅程包 JSON
- 「主页」可以导入旅程包 JSON。

旅程包不包含 API Key，但会包含当前旅程需要复现的故事设置、书库资源、执笔模式配置、严格自定义配置、主弧 / 阶段判断状态与聊天记录。

## 执笔模式

这是当前的主要方向。

执笔模式会产生大量 token 消耗，并在一轮对话中多次调用模型以跟踪故事。至少在当前版本，即使已经做了一定的 system prompt 缓存命中优化，但还是请确保你拥有足够的**经济能力**或**可靠的渠道**来体验执笔模式。

当前支持导出与加载聊天记录和所有设定（旅程包），可以使用此功能分享存档。想要体验好的故事，需要在开始前投入一定时间进行准备，如制定较详细的偏好供模型生成或从外部导入。

## 关于项目

本项目的一部分灵感来源于酒馆，并未对其实现进行参照。
主要方向为“token 换故事质量与体验”，目标是让玩家用尽可能少的工作来体验尽可能高质量的故事，玩家即是作者，也是主角。游戏过程就像 vibe coding，不需要碰类似酒馆的较高门槛，也能得到很好的体验，只需输出想法，就能沉浸在自己与模型创造的故事氛围中。

## 即将实现

- **调控模型**（now）：综合判断，主动调控模型调用，控制故事和成本效益。
- **关系分析模型**（Phase 1.2）：独立分析每个 NPC 的关系阶段、当前情绪、隐藏欲望，让人物推进更细腻。
- **时间线 / 场景连续性模型**（Phase 1.3）：自动维护时间一致性、检测时间矛盾、追踪场景稳定事实。
- **伏笔追踪模型**（Phase 1.4）：自动识别伏笔、维护铺垫 / 可回收 / 已回收状态，向更完整的小说结构靠拢。
- **事件弧进度更新**（Phase 1.5）：让长线事件不靠回合数硬推进，而由决策模型读故事内容判断真实进展。
- **主弧 / 关系图 / 时间线 / 伏笔的完整编辑器 UI**（Phase 2）。
- **模型链路提示词编辑器**（Phase 3）：在设置页暴露每个 system / user 模板，允许玩家覆盖默认。
- **各模型独立配置**（Phase 3）：每个 agent 可独立选模型 / 温度 / token / 重试。
- **执笔模式调度面板**（Phase 3）：每个辅助 agent 独立 `everyRounds` + 启用开关。
- **prompt 输入长度治理**（持续）：故事 prompt 块级长度预算、长流程下记忆 / 摘要自适应扩容。
