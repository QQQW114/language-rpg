# 言灵 · Language RPG

一个由大语言模型驱动的中文文字 RPG / 互动小说前端。

玩家选择故事大纲、角色出身、世界书与随机事件后，由多个模型协作推进旅程：

- **故事模型**：根据设定、历史、长期记忆、背包、人物关系、场景与玩家行动生成正文。
- **决策模型**：根据最新故事提取选项、道具变化、人物关系、场景、时间与天气。
- **记忆模型**：周期性整理外观、服装、承诺、线索、关系等长期一致性信息。
- **摘要模型**：在历史过长时压缩早期上下文。
- **执笔辅助模型**：在执笔模式下提供设定守护、叙事导演、逻辑审校与剧情驱动长线事件。

项目是纯前端应用，所有设置、存档与自定义内容默认保存在浏览器 `localStorage` 中。

## 主要功能

- 中文文字 RPG / 互动小说回合流程。
- 支持有限回合与无尽模式。
- 支持 OpenAI 兼容接口：
  - Chat Completions：DeepSeek、Moonshot、通义千问、OpenAI 兼容代理等。
  - Responses：OpenAI Responses API 或兼容代理。
- 故事大纲、出身、世界书、随机事件预设与自定义书库。
- 启程页可随机生成：
  - 故事大纲
  - 角色出身
  - 开局场景
  - 世界书
  - 随机事件池
- 严格自定义模式：
  - 可改写故事模型 / 决策模型提示词模板。
  - 可配置详细大纲：指定第 X 到第 Y 回合注入剧情约束。
- 执笔模式：
  - 默认每回合自由行动输入，更接近共同写小说。
  - 独立提示词链路，可在不影响游历模式的前提下继续增强。
  - 叙事导演会根据大纲、记忆、世界书和最近剧情规划短期阶段目标。
  - 设定守护者会在故事生成前检查世界书、长期记忆、玩家输入和设定盲区，减少“瞎发挥”。
  - 逻辑审校会定期检查人物、场景、时间线、道具和大纲偏离。
  - 剧情驱动长线随机事件可按概率 / 必定区间生成多回合事件弧。
- 回合中支持：
  - 选择分支
  - 定期自由行动输入
  - 刷新决策
  - 使用 / 丢弃 / 获得 / 损毁 / 修改道具
  - 场景跳转
  - 时间与天气追踪
  - NPC 好感、身份、描述、外观细节追踪
  - 记忆锚点标记
- 长期一致性记忆：
  - 可设置每隔多少回合整理一次。
  - 可设置最大记忆长度。
  - 用于减少模型遗忘人物外观、服装、约定、计划、未解线索等。
- 聊天记录与旅程包导出：
  - 导出聊天记录 Markdown。
  - 导出完整旅程包 JSON，包含存档、故事设置、书库资源、严格自定义配置等。
  - 首页可导入旅程包，方便分享存档。
- 历史编辑：
  - 可编辑 / 删除某轮玩家行动或模型回复。
  - 可编辑当前决策选项。
  - 可重新请求最新一轮故事，并可附加重要参考提示。

## 快速开始

### Windows

双击：

```bat
start.cmd
```

首次启动会自动执行 `npm install`。

### macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

启动后访问：

```text
http://127.0.0.1:5173
```

## 首次使用

1. 进入「设置」。
2. 填写：
   - API Base URL
   - API Key
   - 请求格式
   - 故事模型
   - 决策模型
3. 按需填写：
   - 摘要模型
   - 长期记忆模型
   - 随机生成模型
4. 返回主页，点击「启程 · 开始新旅程」。

> API Key 只保存在本地浏览器 `localStorage`，不会被项目主动上传到其他地方。

## 推荐模型配置

推荐：`deepseek-v4-pro` / `deepseek-v4-flash` 或能力相近的长上下文模型。

- **故事模型**：`deepseek-v4-pro` —— 故事生成，越强越好。
- **决策模型**：`deepseek-v4-flash` —— 场景轮换、人物关系、背包道具。
- **摘要 / 记忆模型**：`deepseek-v4-flash` —— 压缩上下文。
- **随机生成模型**：`deepseek-v4-pro` —— 生成世界书、人设、随机事件，越强越好。

## 存档与数据

本项目主要使用 Zustand persist 写入浏览器本地存储：

- `lrpg.settings`：模型 API、温度、记忆设置、故事风格等。
- `lrpg.games`：存档、聊天记录、背包、NPC、场景、长期记忆等。
- `lrpg.content`：自定义故事大纲、出身、世界书、随机事件。

如果更换浏览器、清理站点数据或换设备，本地数据可能丢失。建议使用「旅程包」导出重要存档。

## 内容导入 / 导出

- 「书库」中可以管理故事大纲、出身、世界书、随机事件。
- 「游戏页」可以导出：
  - 聊天记录 Markdown
  - 完整旅程包 JSON
- 「主页」可以导入旅程包 JSON。

旅程包不包含 API Key，但会包含当前旅程需要复现的故事设置、书库资源、执笔模式配置、严格自定义配置与聊天记录。

## 项目结构

```text
src/
  pages/        页面级流程：主页、启程、游戏、设置、书库
  components/   UI 与游戏面板组件
  store/        Zustand 状态与 localStorage 持久化
  services/     模型调用与游戏服务
  prompts/      故事、决策、记忆、摘要、评分、执笔辅助等提示词
  presets/      内置故事大纲、出身、世界书、随机事件
  lib/          通用工具、严格自定义、旅程包等
  types/        TypeScript 类型定义
```
