# v0.6.1 发行说明（2026-10-21）

本版是 gemini-4-argon 第二轮增量复审后的提示词微调与零风险修正，不改变存档/设置协议。

## 修正

- **P0 混合端点 profile 绑定复核**：确认 `storyProfile` 读取的是**实际生效的 story 模型**（不是全局/规划模型）；`planner=deepseek + story=gemini` 时正确选择 `expressive`，不会误挂 compact 微示范。新增混合端点回归测试钉住。
- **P1 planner_pre 节拍数彻底收口**：`beatsThisTurn` 数量不再引用叙事速度（删除最后一处“慢叙事只写 1 个”残留）：
  - 严格遵循 0~1 个；
  - 标准推进 1 个；**本轮没有随机事件时最多 2 个**；
  - 自由发散 1~3 个。
- **P1 随机事件 targetId 防呆**：要求只填候选目标的**纯 ID 字符串**，严禁拼接 `beat:` / `thread:` 等前缀，减少 invalid binding 警告。
- **P1 标准档篇幅区间下移**：`【STORY_AUTONOMY】` 标准档改为「目标 800~1100 字，硬上限不超过 1200 字；若同时安排随机事件，须与主线交锋合并在此篇幅内，不得额外拉长」。
- 按复审建议，**没有**给 story 重试追加“请完整写完”类提示，避免诱发注水；阶段级重试继续逐字节复用原请求。
