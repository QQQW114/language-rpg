# v0.5.2 发行说明（2026-10-20）

本版补齐上一版遗漏的两个预设主角出身，并加入「故事推荐出身」机制；存档格式与协议不变。

## 新增

- **故事推荐出身 `StoryOutline.backgroundIds`**：
  - 故事可声明自己的推荐主角出身；启程页选择故事后只展示这些出身；
  - 切换故事时自动选中其第一个推荐出身；
  - 未声明的（自定义）故事仍展示全部出身，旧行为不变。
- **两个预设主角补齐**：
  - 《余温代行人》→ 旧港维修学徒 · 林澈（`bg_apprentice_linche`）
  - 《赝品修复师》→ 古玩斋替工 · 苏砚（`bg_restorer_suyan`）
  - 《错位青春》→ 大一新生 · 曦宇（`bg_freshman_xiyu`）
- 内容库校验会保留并清洗 `backgroundIds`；`tests/presets.test.ts` 增加出身引用与内置主角断言。

## 修复

- 0.5.1 只导入了 Gemini 生成的两个故事与两本世界书，漏掉了两个故事专属主角出身 → 启程页缺少这两个预设角色。本版已导入并绑定，同时通过「按故事过滤」避免专属主角出现在其它故事里。

## 兼容性

- 存档格式未变（`SAVE_STORAGE_VERSION = 2`）；旧存档只保存创建时的大纲/出身副本，不受新预设影响。
- 自定义故事若未设置 `backgroundIds`，与之前一样可选择全部出身。
- 已创建但尚未开始的旅程不会自动变化；新启程时按故事过滤。
