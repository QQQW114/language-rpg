# v0.6.0 发行说明（2026-10-21）

本版是 v0.5.2 之后的提示词与运行时可靠性升级，重点：**跨模型文风、失败恢复、混合端点与故事推进权限**。

## 新增

### Prompt Pack v2.2 / v2.2.1（gemini-4-argon 复审落地）

- **故事推进权限**：`严格遵循 / 标准推进 / 自由发散` 三档，与叙事速度正交；它接管单回合篇幅、展开幅度与 `beatsThisTurn` 数量上限（1 / 2 / 3）。叙事速度四档改为纯镜头焦距/剪辑节奏。
- **文风 profile**：按 story 模型自动选择 `compact`（保留文风微示范）或 `expressive`（省略微示范、使用短锚点）；profile 不再携带独立数值篇幅带，`【STORY_AUTONOMY】` 是篇幅与展开幅度的**唯一来源**。
- **去过度调整**：删除“把结果写透写扎实”的催写指令与段末总结陈词；句式黑名单降级为通用文学原则（反浓妆副词、反“不是A而是抽象B”、反慢镜头套话）；planner_pre 增加“已演过的包袱/台词/已确认信息不得复读”。
- **JSON 稳定性**：planner_post 约束 evidenceQuote 等字符串内引号一律用中文引号；planner_pre / planner_post 非法 JSON 自动做一次修复重试（只重发当前阶段）。

### 失败恢复

- **正文截断防护**：story 正文 <120 字、句尾缺少终结标点、或疑似供应商错误文本（内容审核/密钥/限额等）时判本回合失败、不提交；61 个真实回合扫描检出 3/3 断流、0 误杀。
- **分层重试**：
  - 传输层：网络错误 / 429 / 5xx 自动重试最多 2 次（指数退避）；认证/取消不重试；
  - 解析层：规划 JSON 修复重试；
  - 回合层：GamePage 瞬时失败自动重试 1 次；结算失败先自动只重试结算；
  - 输入兜底：最终失败把未提交输入写回草稿，刷新页面可恢复。
- **阶段级重试**：story 阶段失败时复用本轮已成功的 planner_pre，只重跑 story；不复用失败尝试正文，UI 收到 `phase_restart` 会清空流式预览，不会出现两次尝试拼接。

### 混合端点

- 设置新增“故事模型独立连接（可选）”：`storyApiBaseUrl` / `storyApiKey`，留空分别继承全局；planner_pre / planner_post / 结算 / 续跑始终走全局，story 可单独指向 gemini 等反代；联网搜索/规划 JSON 只看全局；`reasoning_effort` 按阶段端点判定。
- 可用“planner/post 用 deepseek-flash 官方 + story 用 gemini”组合：真实 3 回合验证中 planner 前缀缓存保留（pre 31.9% / post 28.3%），story 0 缓存符合预期。

## 已知问题 / 边界

- **标准档篇幅偏长**：deepseek 20 回合中标准档 p50 1275 字、3/20 超过 1500 字（目标 800~1200）；属于模型偏长而非结构错误，留给后续版本继续收紧。gemini 标准档 p50 1421 字同样偏长。
- **gemini 反代无前缀缓存、单回合较慢**（~2 分钟/回合），且偶发内容审核误判；错误文本已被护栏识别，不提交正文。
- **显式 `thinking:{type}` 仍会发往所有阶段**：混合端点下若 story 反代不接受该字段，可能需要后续按端点拆分；当前未观察到实际报错。
- **story 阶段重试最多 2 次**；两次均失败后仍会走前端整回合自动重试（第二道防线），最坏情况 4 次 story 调用。
- **结算失败（failedPartial）正文仍只存在当前页面会话**：刷新后未提交正文与“仅重试结算”入口会丢失；当前已把输入写回草稿。

## 兼容性

- 存档格式未变（`SAVE_STORAGE_VERSION = 2`），旧存档无需迁移；v2.2.1 的 `storyAutonomy` 缺省为 `standard`，旧档 hydrate 自动补。
- 设置表单新增可选字段，默认空串继承全局，旧设置行为不变。
- 线上部署为纯前端版本，API Key 仍只保存在浏览器本地 `lrpg.settings.v2`。

## 升级

无需任何迁移，直接刷新线上页面即可；如使用自定义 API 端点，可在“设置 → 故事模型独立连接”中按需填写。
