# 言灵 v0.3.0：故事工坊与命运驱动引擎

v0.3.0 是一次整体重构。项目从堆叠多个设定维护 Agent，转向依赖强模型能力的双模型链路，并用程序侧结构化状态保护长期一致性。

## 本版亮点

### 故事工坊

- 自定义故事大纲、幕、故事节和每幕的目的/结局方向。
- 自定义结构化世界书条目。
- 复制内置“错位青春”作为完整参考模板。
- 浏览器本地保存，支持编辑、复制、删除和 JSON 导入/导出。

### 命运驱动的双模型故事

每轮按照“规划写前 → 故事正文 → 规划写后 → 程序提交”运行。世界书和故事大纲提供方向，模型根据玩家行动寻找新的实现路径。玩家可以偏离地点、身份或原路线，但关键人物、故事功能和最终目标仍会被自然迁移和推进。

### 更成熟的模型交互

- 规划模型可按需搜索旧人物、关系、承诺、事件和事实。
- 可配置规划上下文预算与单阶段工具调用上限。
- 支持 DeepSeek JSON、思考模式、reasoning effort 和 KV cache 用量展示。
- 实时活动树展示规划、推理、工具调用、状态提交及每阶段 Token 消耗。

### 更可靠的前端

- 支持生成期间继续输入并排队，可取消队列。
- 支持终止当前回合、失败重试、重新生成，以及修改最近输入后确认重试。
- 支持慢速、标准、快速和时间跨越叙事节奏。
- 修复自动额外推进回合、后台页面状态、旧请求重复提交和工具开关错位等问题。

## 重要说明

- v0.3.0 不兼容旧版存档。
- 存档和自定义故事默认只保存在当前浏览器中，请使用 JSON 导出及时备份。
- 本项目不附带模型服务，使用前需要在设置中填写兼容的 API 地址、模型和 API Key。
- 请勿把 API Key 写入导出文件、公开日志或仓库。

## 验证

- TypeScript 与 Vite 生产构建通过。
- 状态 Patch 自动测试通过。
- 使用实际双模型链路完成 10 回合长线测试，上下文查询工具能够在旧信息确有需要时按需调用。
