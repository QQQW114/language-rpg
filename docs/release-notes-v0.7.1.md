# v0.7.1 发行说明（2026-10-22）

本版是 0.7.0 之后的前端体验小修，不改变故事引擎与提示词。

## 修复

- **不再自动向下滚动**：
  - 故事生成过程中，正文流式增长不会再把视口往下拖；
  - 一轮生成完成后，也不会自动跳到页面底部；
  - 右下角「回到最新」/阅读导航的跳转仍然可用，但只由玩家主动触发。
- **清理技术感过重的提示**：
  - 「双模型链路正在运转，点击阶段节点可检视实时思考链与工具轨迹」改为「正在写这一回合的故事…」；
  - 空闲态「三阶段推演与状态对账已完成」改为「这一回合的故事已经写好了」；
  - 「LIVE TELEMETRY / SETTLED」改为「生成中 / 已完成」。
- **文档口径**：不再把「传送室字面演出」「NPC 误诊台词」这类主观文风细节列为 0.7.x 待办；除非玩家明确要求或验证阶段发现实际体验问题，不为这类小问题收紧提示词。

## 测试

- 单测、build、e2e 44/44、test:patch 全部通过。
- 改动集中在 `GamePage.tsx`（滚动逻辑）与 `ModelActivityPanel.tsx`（文案），不涉及 engine/patch/store。

## 兼容性

无存档/设置/协议变化，覆盖部署即可。
