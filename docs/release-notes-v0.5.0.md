# v0.5.0 发行说明（2026-10-20）

本版把「言灵 · Language RPG」的 V2 命运驱动链路补齐为可日常游玩的生产基线，并完成一次针对文风的提示词重构。

## 亮点

### 1. 程序权威幕系统（P1–P5）

- 幕推进由程序按故事节完成情况决定：常规轨自动推进，改道轨携节挂账（终态 ≥50%、非终态须 `reframed/weakened` 且有 `currentPlan`、≤2 条）；模型自报的幕不一致会被忽略并留警告。
- 三幕聚焦窗口（≤900 字）、本轮节拍（≤3 条）、世界书稳定/动态拆分、随机事件目的绑定与三态闭环、节奏审计与下轮软纠偏全部落地；`SAVE_STORAGE_VERSION` 2，旧档 hydrate 自动补齐幕字段。
- 20 回合真实长局：自动切幕 2 次、随机事件 19 个全部有绑定、升华收尾 0。

### 2. 长文阅读前端（Gemini 方案集成）

- 卷宗目录、回合书签、字号/行距/版心、回到最新、跨幕题跋；司辰仪模型活动面板；五层金线更新特效与路由金线过渡；侧边栏特效定时器与漏块问题修复。

### 3. Prompt Pack v2.1（本版核心）

- 规划只给「客观结果底线 + 戏剧悬置切面」，故事模型独占场景与台词；story 用户消息删除 7 个工程元字段并追加近因锚点；planner_post 放宽 `satisfied` 判定并禁止把临时描述固化为人物名。
- 真实 A/B（同一批 20 条输入、`deepseek-flash`）：状态标签当人名 48→0、`【stopBoundary】` 泄漏 1→0、慢镜头词 14→1、盯视计时器 4→0；v2.1 中位字数 1,193（v2 724、短回合 6→0），T11 进入第三幕，T15 `satisfied=8`；输出 token 与 v2 持平而正文多 58%。
- 模型分级：日常用 flash；高优品质档只把 story 阶段切到 `deepseek-v4-pro`，规划/结算继续 flash。

### 4. 检索与工具

- `search_story_context` 重写为纯函数模块：CJK 整段 + bigram、停用词、覆盖率排序、500 字命中锚点证据、同来源 ≤2、`matchedTerms/score`、0 结果可执行提示。
- 可选官方联网搜索（默认关）：`web_search` 仅在「工具开启 + `plannerWebSearchEnabled` + 官方 DeepSeek base + 有 Key」时挂载，每回合最多 1 次，失败降级；长查询低置信度回退（`lowConfidence`）；`ori_question` 带玩家输入。

### 5. 修复

- 节奏审计把台词/计划性时间词误判为跨日推进（`paceGuard`）——现在统计前剔除引号台词与「今天/明天/上周… + 时段词」组合。
- 切幕后 `currentStage` 空白——程序兜底「本幕开篇」。
- hydrate 丢失随机事件审计字段、`turnRecords[].calls` 缺失导致写盘抛错、侧边栏特效提前清空/漏块等。

## 验证

- 单元测试 **555/555**（20 个测试文件）；`test:e2e` 43/43；`test:patch`、`test:storage` 通过；`npm run build` 通过。
- 真实链路：`test:real` 支持 1–40 回合长局、分阶段缓存统计与长局评测；20 回合实测 p50 1,135 字、随机事件 19 个全部绑定、缓存预热 pre 17.3% / story 22.0% / post 16.6%。
- Prompt Pack v2.1 15 回合验证：中位 1,193 字、<650 字回合 0、T11 进第三幕、T15 `satisfied=8`。

## 升级注意

- 存档格式版本 2：旧存档自动迁移，无需手动处理；仍建议先在主页导出备份。
- 设置新增 `plannerWebSearchEnabled`，默认关闭；开启需要官方 DeepSeek 地址与 Key。
- 模型仍可分别设置 planner/story/post；story 用 `deepseek-v4-pro` 时无需修改提示词。
- 浏览器端会保留旧的 `lrpg.settings.v2`，未知字段被忽略，不会回滚。

## 已知边界

- 节奏检测是保守启发式（意象式升华可能漏报）；前端 React 组件行为不在单测覆盖内，需浏览器冒烟；联网搜索依赖官方端点与计费；长局存档体积仍受 5 MB localStorage 配额约束（25 回合约 364 KB）。
